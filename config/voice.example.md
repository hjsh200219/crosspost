# Brand Voice Guide

Copy this file to `$CROSSPOST_HOME/voice.md` (default: `~/.crosspost/voice.md`)
and edit it to describe YOUR voice. The publish skill reads this file before
drafting any post — everything below is an example; replace it with your own.

## Identity

- Author: (your name / brand)
- Positioning: (e.g. "AI consultant writing for non-technical business owners")
- Audience: (who reads your posts, what they care about)

## Tone

- Language: (e.g. Korean, polite but direct / English, conversational)
- Sentence rhythm: (short punchy vs. long-form explanatory)
- First person: (I / we / brand name)

## Structure preferences

- Hook style for the first line (this is what feeds show — make it count)
- Preferred post length per channel (LinkedIn long-form vs. X thread vs. Threads casual)
- Hashtag policy (none / 3 max / channel-specific)
- Emoji policy

## Hard rules

- Things you never say (competitor names, hype words, clichés to avoid)
- Compliance constraints (industry regulations, disclaimers)
- Attribution rules (when introducing other people's work, always credit and link the original)
